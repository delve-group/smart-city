## Stan

Repozytorium zawiera dokumentację i działający wzornik HTML/CSS. Aplikacja React, komponenty shadcn/ui, backend i integracje nie zostały jeszcze zainstalowane ani zaimplementowane. Wzornik pokazuje docelową stylistykę i korzysta z tych samych tokenów, które wykorzysta aplikacja.

Motywy: **Civic** — jasny, urzędowy (domyślny); **Signal** — ciemny, futurystyczny i geometryczny. Zakres produktu i stos backendowy pozostają do ustalenia przy pierwszej funkcji.
